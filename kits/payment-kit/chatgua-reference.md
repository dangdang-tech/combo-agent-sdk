## 借鉴为通用 Agent 商业模式

从这些公开设计可以抽象出：先用免费功能和任务奖励降低试用门槛，再通过预付额度购买和服务档位提供明确价格。较大套餐增加单位金额可买到的额度，形成购买选择。这是产品机制分析，没有转化率、留存或营收证据。

Combo 可复用这个机制，让创作者定价自己的工具、咨询、报告或 API 服务。点数名称、币种、模型和支付渠道都可不同；服务价格要独立于底层模型成本。

以下事项不能从本次材料确认：额度是否过期、正式退款条款、订阅或自动续费、税费、服务端扣点时机与幂等、拒付处理，以及创作者分账或实际到账。kit 中相关合同均为 **Combo 的设计建议**，不是 ChatGua 已有实现的描述。
